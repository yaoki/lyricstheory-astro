声を抜く

伴奏の入った曲から歌だけを取り出します。ここだけはブラウザの中で終わりません。

録音を読み込む の下ごしらえにあたる工程です。抜いた声を、そのまま向こうへ食わせます。

伴奏が入ったままでは測定になりません。 低い方の帯はベースとキックが埋めてしまい、周期を探せばベースラインに食いつきます。 声が出ているかを見ているつもりで、鳴っているのは伴奏です。 無声化のように「声帯が振動しているか」を見たいときは、この工程を飛ばせません。

01wav にする

afconvert は macOS に最初から入っています。Homebrew も ffmpeg も要りません。

mkdir -p ~/lyric-analysis
afconvert -f WAVE -d LEI16 '/path/to/曲.m4a' ~/lyric-analysis/song.wav

02demucs を入れる

仮想環境を切るのは、最近の macOS の Python が externally-managed-environment で pip install を拒むためです。

cd ~/lyric-analysis
python3 -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install demucs

torch を引くので 1〜2GB 落ちてきます。初回実行時にモデル（300MB ほど）も追加で落ちます。

03声を抜く

demucs --two-stems=vocals song.wav

--two-stems=vocals は「ボーカル / それ以外」の2つに割る指定です。4分割より速く、伴奏の内訳は要りません。出力はこうなります。

separated/htdemucs/song/vocals.wav
separated/htdemucs/song/no_vocals.wav

M シリーズなら4〜5分の曲で数分。精度を上げたいときは -n htdemucs_ft を足します（4倍ほど遅い）。

04読み込ませる

録音を読み込む を開き、vocals.wav を選びます。伴奏が無いぶん声紋の縞がはっきり出て、声の高さの線も途切れません。

倍音の横縞が並んでいれば、声帯が振動しています。縞が消えて霞がかった塗りになっていれば、そこは声になっていません。

踏みやすいところ

  • 伴奏込みで見て、全部に声があるように見える。いちばん最初にやる失敗です。demucs を通す前のファイルを見ても意味がありません。
  • コマンド行の末尾に注釈を書かない。macOS の既定シェルは、対話入力では # をコメントとして扱わないことがあります。brew install ffmpeg  # 説明 と打つと # が引数として渡り、無関係なエラーが出ます。
  • 再生位置の表示を、フレーズの境界と取り違えない。DJ ソフトなどの経過時間はスクラブした場所であって、フレーズの終わりではありません。時刻は vocals.wav を直接聴いて取ります。解析にかけるのと同じファイルなので、ずれが起きません。
  • モーラを均等に割らない。歌唱は等間隔ではありません。フレーズの長さをモーラ数で割った値を境界に使うと、有声であるはずの音（ラ行など）まで無声と出ます。境界は耳で取ります。

置き場所

抜いた vocals.wav は市販録音の派生物です。~/lyric-analysis のような作業ディレクトリで完結させ、公開する場所には置かないこと。
