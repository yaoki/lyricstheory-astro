  食い違いを見つけたら schema に合わせ、ここも直す。

  1カードあたりの歌詞引用は、分析に必要な最小フレーズ（1〜2行以内）に限定する。

  elements 配下にも同様に適用する。

  引用に使えるのは貼付された歌詞だけで、記憶・検索から補完しない。
  ただし**照合は義務**で、発売年・作詞者ともども歌詞サイト2つ以上で確かめてから書く
  （CLAUDE.md「歌詞の扱い」「外部事実の扱い」）。確かめられない項目は
  `sources` に書かず、`unverified` に残す。

  【seed と作業ノートの分離（重要）】
  カード本文には「観察」だけを書く。
  裏取り控え（流通歌詞との突き合わせ、メタデータ確認等）は「作業ノート」であり
  repo に書かない（Obsidian / iPhone メモに退避する）。
  書誌情報は sources frontmatter に置けば十分で、本文で重複させない。

  推測（制作過程・コノテーション・聴き手の心理）は、やおき自身の仮説であっても

# figure（任意）— X のサムネイルと本文に出る図。書かなければタイトルのみの絵になる。

#   npm run figure -- 'おと「し」て「し」まう'
#   npm run figure -- --pivot 'カ行子音' --repetition c '<LyricQuote の中身をそのまま>'

#   pair      離れた2箇所の対比。labels は省略できない。展開・並べ替えは mode: expansion

#   consonant 子音の並びを歌詞の上に振る
