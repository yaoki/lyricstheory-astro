# elements のネットワーク化 — 実装計画

2026-08-13 作成。5領域の並列調査（用語カード／分類／外部リンク／お試しツール／posfie）と、その統合から起こした計画。**数値はすべてこの日時点の実測**であり、カードが増えれば変わる。

やおきさんの狙いは「利便性とネットワーク張り」で、最終的には**分析カードと書籍・YouTube・過去記事を相互にリンクし、著者や YouTuber との相互送客の仕組みを作る**ことにある。以下はそこへ至る順序である。

## 全体は3層に分かれる

1. **内部のネットワーク** — 用語カード、分類と一覧、related の整備
2. **外部への接続** — books / webrefs との双方向リンク、posfie 過去記事
3. **入口** — お試しツール（図を作って X に投稿）

順序がある。**内部が空のまま外部リンクを増やすとリンクが個別カードにぶら下がって散らばり、入口を作っても中が回遊できなければ素通りされる。**ただし入口（ツール）は既存コードの再利用なので、他と依存せず並行できる。

## 決定済み（2026-08-13、やおき裁定）

- **D1: 用語カードは `elements` に置く**（`/elements/<用語slug>/`）。`concept` コレクションは使わない → CLAUDE.md「用語カード」節に記載済み
- **D3: 定義の正本は `docs/theory-glossary.md`。**カードに書くのは要約と実例で、定義文の写しではない → 同上
- **D2: 予約語検査だけ入れ、URL は切らない。**`artist` / `song` / `type` / `phoneme` / `era` / `tag` を card id の禁止語にする（検査7）
- **D4: フィールド名は `song` / `terms` / `books` / `webrefs`。**`song` は `{ title, artist }` の 2 項目だけ持ち、書誌の完全形は `sources` に残す（二重化を避ける）。`terms` は `related` と分ける（逆引きの意味が違う）。外部文献は `relatedWorks` 1 本ではなくコレクションごとに分ける（Astro の `getEntry` がコレクション名を型で要求するため）
- **D5: `type` は使用中6語 + `term` の 7 語で enum 化。**未使用の `rhyme` / `prosody` は入れない。使われていない語彙が残ると分類が語彙の側に引きずられる

- `song.artist` は title からの抽出値をそのまま使う。1枚だけ長い表記（`ryo（supercell）feat. 初音ミク`）になるが、title と食い違わせると検査8 が組めない
- 検査5〜8 は、壊したカードを一時ディレクトリに置いて**7ケースすべてが落ちること**と、正常カード2枚が素通りすることを確認済み

## お試しツール（図を作って X に投稿）

`src/lib/og/templates/` の4つ（single / pair / pivot / consonant）は**SVG 文字列を返す純粋関数**で、Node 依存は `render.ts` の `@resvg/resvg-js` と `node:fs` だけ。SVG を DOM に出せばブラウザで動く。PNG 化は canvas でできるのでサーバー不要。

**設計原則: ツールは判定せず、描くだけ。**この理論の要点は「指させる/記述できる」であって自動判定ではない。「あなたが囲んだ音を図にします」に留める。判定するツールは理論を単純化して裏切る。

**署名を差し替える。**図のフッターは現在「やおき / lyricstheory.com」。**読者が作った図にやおきさんの名前が入ると、他人の分析がやおきさん名義で流通する。**道具の出所（「作図: lyricstheory.com」等）に変える。

- **D7: フォント。**案A システムフォント任せは CLAUDE.md「システムフォントには依存させない」と正面衝突。**推奨は案C**（Bold かな＋漢字2136字 446KB ＋ Regular かな 50KB）で OG と同じ字形になる。`public/` を避ける理由は「8.8MB が dist へコピーされる」ことなので、1ページ限定の496KBはこの理由に当たらない。ただし明文の規則を一部上書きするので、CLAUDE.md に例外条項を書き足すことが条件
- **D8: 対応図法。**上限8は「8枠」であって「8音」ではない。1枠4文字×8枠＝連続32文字（single）、pivot は行の全文65字、consonant は96字が図に焼かれる。CLI ではやおきさんの自制が最後の砦だったが、公開ツールに自制は無い。**推奨: 初版は single のみ・1枠1文字強制・総字数上限**
- 歌詞をサーバーに送らないこと（静的サイトなので自然に満たせる）を明記する
