# 歌詞音韻分析の記述規範

日本語歌詞の音韻分析を書くための規範。

## 適用範囲

本（『近代日本語歌詞のエクリチュール──現象を記述する』以降の新規執筆分）、lyricstheory.com の essays と elements、wiki の散文 ── 分析散文のすべてに適用される。齟齬があれば本文書が勝つ。

ただし理論内容の典拠序列とは別軸である。何が真かについては頒布版の本文が最高位に立つ。本文書が定めるのは、どう書くかである。

**この文書が正本である。** 写しを置かない。参照するときはこのファイルを指すこと。

```
https://raw.githubusercontent.com/yaoki/lyricstheory-astro/main/docs/style-rules.md
```

## 規則

### 規則1:時制の現在進行優先
- 過去形「〜した」「〜してきた」より、現在進行形「〜している」を優先する
- 参照対象(他の著者や作品)は、今も働いている現象として扱う

### 規則2:実体化する語の回避
- 「もの」「こと」のような曖昧な代名詞・形式名詞を安易に使わない
- 可能なら具体名詞(「現象」「方法論」等)で指す
- 分析対象を実体ではなく現象・関係として扱う存在論と文体を一致させる

### 規則3:メタ記述の回避
- 「〜というものだ」「〜という立場だ」のように、自分の立場を名詞化して対象化する書き方を避ける
- 「〜したい」「〜と思う」のように、行為・意志・欲求として直接書く
- 書き手を固定化された自己として示さず、行為する身体として示す

### 規則4:断定の留保
- 「AはBである」の完全な同一性主張より、「AとBはほとんど同じ」のような程度の留保を入れる余地を探す
- 完全な同定を避ける誠実さ

### 規則5:「である」の連続を避ける
- 論文調の硬さを招きやすい
- 他の述語形との組み合わせでリズムを作る

### 規則6:印象的な形容を音韻分析で使わない
- 「明るい／暗い」「柔らかい／硬い／硬質」「肌理が堅い」などは印象であって事実ではない
- 音声学的特徴（前舌／後舌、高舌／低舌、破裂音／摩擦音／鼻音／流音、両唇／歯茎／軟口蓋）に置き換える
- または頻度・分布の事実（出現個数、占める割合）として記述する
- 2026-04-19追加。川原繁人（一般書）が印象批評を事実として書いたことへの反省として

### 規則7:引用は歌詞ファイルの範囲内に限定する
- `lyrics/` ディレクトリのファイルに書かれた歌詞以外からフレーズを引用しない
- 記憶・ネット情報・一般的知識に依拠した引用は幻覚の温床
- 必要であれば `lyrics/` への追記を依頼し、追記範囲の中で分析する
- 2026-04-19追加。スピッツ「ロビンソン」の幻覚引用事件（「きみと会えた」「ぼくらの魔法」「この胸に」）への反省として

### 規則8:先行研究由来でない一般化は具体的数値として示す
- 「〜する傾向が強い」「〜することが多い」のような曖昧な一般化は避ける
- 実際に対象を数え、具体的な頻度・比率として提示する
- 典拠がある場合は明示的に引用する
- 2026-04-19追加。「草野は他曲でも破裂音を避ける傾向が強い」の典拠なし一般化への反省として

### 規則9:事実と修辞を節として分離する
- 実務ルール: 修辞的な結び（詩的トーン、文学的評価）は節タイトルで明示する（例: 「結びに代えて──」）
- 節の冒頭で「以下は事実記述ではなく修辞である」と断ることも有効
- 根拠: 本書は科学的アプローチ（音声学、スペクトログラム）と文学的アプローチ（文化・文学としての歌詞の鑑賞）を併用する。前者と後者の境界を曖昧にすると読者を騙すことになる。本書の立場表明（科学的方法論はあくまで「なぜ歌に感動するのかという神秘」へ向かうための道具）はまえがき／第1章に別途記述する
- 2026-04-19追加

### 規則10:数値表記はアラビア数字
- 測定値・カウント値（モーラ・拍・回・度・層・つ・曲・行・操作・人・章・節 等）はアラビア数字（半角）で書く。例：6モーラ、3拍、4操作、3層、2フレーズ頭韻
- 例外：副詞句「第一に・第二に・第三に」は漢数字のまま（順序提示の慣用表現として残す）
- 例外：固有名詞・歴史的呼称・成語の数字（「三位一体」「一次資料」「全体の一部」「ロンド3部形式」等）は対象外。機械的に変換しない
- 既存原稿（full_manuscript_v1.5.md 等）は2026-05-20の一括置換で適用済み
- 2026-05-20追加

### 規則11:「距離」を使わない
- 反復の効果や操作のスケールを記述するときに「距離」「distance」を使わない
- 根拠1：空間隠喩（メートル・近遠）であるため、本書の時間意識ベース（想起と回帰）の立場と整合しない
- 根拠2：日本語ラップ文脈で「飛距離」（R-指定・ZORN）が「韻の強度」を測る用語として広まったが、本書はこの政治的・闘争的含意を採用しない（Sagishi も「内輪ノリで決められた不適切な用語」と批判）
- 代替：時間的・量的概念（**スパン**、**span**）、または具体的記述（同一フレーズ内／フレーズ間／曲全体）、または本書の理論用語（**短期反復**、**回帰反復**）
- 既存原稿で既に明文化済み：full_manuscript_v1.5.md L160（「反復の効果を、『距離』という語では記述しない」）、L167、L311、L413
- ドラフト ch3_section_2_1_mikuru_three_layers.md で2026-05-20に7箇所違反→「スパン／span」に全置換
- 2026-05-20追加

### 規則12:書記上の最小単位は「フレーズ」と呼ぶ
- 全角スペース区切りの書記上の分節を **フレーズ** と呼ぶ
- 例：「あすも　あのひとに　あえますように」は3フレーズ
- 「句」は使わない。理由：（1）本書は第4章§2.2 Sagishi 引用箇所で「アクセント句・イントネーション句を押韻単位として厳密には採用しない」と明言済み（full_manuscript_v1.5.md L699）、「句」を別の意味で導入すると衝突する（2）言語学の「文節」「節」「句」とも紛らわしい
- 英語では **phrase** を使う
- 2026-05-20追加

### 規則14:理論用語の英訳を初出時に併記する
- 本書の理論用語は、**本書全体で初めて出てくる箇所**で英訳を `括弧書き` で併記する
- 以降の出現箇所は和語のみで運用
- 対象は4操作・反復の類型・想起と回帰・頭脚一致など、本書独自に立てた／本書で再定義した概念
- 表記例：「**並行**（parallel）」「**倒置**（retrograde）」「**展開**（expansion）」「**圧縮**（contraction）」
- 根拠：英訳併記により（1）英語圏音楽理論との対応関係が読者に開かれる（2）Schoenberg の動機操作論に着想された本書の用語が、英語圏理論用語と関連付けやすくなる（3）将来の英訳・抄訳の基礎になる
- 4操作の英訳は2026-05-20リサーチで確定（**本書独自の定義**であり、Schoenbergのオリジナルの体系化ではない）：
  - 並行（parallel）── ABC→ABC、原型の保存と反復累積
  - 倒置（retrograde）── ABC→CBA、逆順配置。**inversion は音程反転で別概念のため採用しない**
  - 展開（expansion）── もとの音列が順序保存的に保たれたまま、その間に新しい要素が挿入される操作。AC→ABC は最短記法、一般には A B C → A x B y C z のように複数装飾が間隙に挿入される。Schoenberg の developing variation、Coltrane の sheets of sound、Pat Pattison の sonic fabric と同じ性格（2026-05-20追加。第1章 §4.3 [^expansion-references] 参照）
  - 圧縮（contraction）── もとの音列の一部要素が脱落し、より短い音列に縮減される操作。ABC→AC は最短記法、一般には A B C D E → A C E のように要素が間引かれる。展開と対称的
- Schoenbergのオリジナル：12音技法の **原型（prime）・反行（inversion）・逆行（retrograde）・逆反行（retrograde-inversion）＋移高（transposition）**。対象は音列レベル。本書の四操作は動機・フレーズ・反復という別の対象に独自定義したもので、Schoenberg自身が「並行・倒置・展開・圧縮」の四操作として体系化したわけではない
- 近接用語との峻別が必要：
  - **augmentation / diminution** ＝ 音価の拡大／縮小（本書と別概念）
  - **intervallic expansion / contraction** ＝ 音程の拡大／縮小（本書と別概念）
  - 本書の expansion/contraction は **phrase / motivic** のレベル
- 2026-05-20追加
- **想起・回帰の英訳は未確定**（2026-07-27 追記）。「想起」は本書で暫定の語として導入されている。「回帰反復」は沼野雄司『ファンダメンタルな楽曲分析入門』（2017、pp.24-32）からの借用で、同書は日本語文献のため**英語の確定訳が存在しない**（現物確認済み）。lyricstheory の slug で用いている `return` は西洋形式論の慣用に基づく採用にとどまる。`recursion` は計算機科学の「再帰」と衝突するため採用しない。英語で書く場合はこの留保を明示すること

### 規則13:「頭脚一致」── Sagishi note との独立収斂を脚注で記す
- フレーズペアの頭と脚が同時に一致する現象を **頭脚一致**（英：head-foot alignment）と呼ぶ
- これは展開操作（AC→ABC）が2つ並んで観察される結果の状態であり、一致度はスペクトラム（頭脚完全一致 → 頭韻のみ → 脚韻のみ → 部分一致）をなす
- **同じ用語が Sagishi「粘性と響きの押韻論、子母音の効果」（note, 2021）にも独立に登場する**ことが2026-05-20に判明。Sagishi は同現象を「中間音無視」と命名。本書の命名は一致する両端の側から、Sagishi は無視される中間の側から、同じ現象を呼んでいる
- 本書で頭脚一致を初出させる節（第3章 §2.2）で、脚注として Sagishi note との関係を必ず記す（citation key: `sagishi2019_nensei`）
- 第1章 §4.3 末尾でも、4操作（展開）との関係＋スペクトラム性を理論編で予告する補注を入れる
- 2026-05-20追加

### 規則15:「枠」ではなく「図式（schema）」を使う
- 概念を包み込む線的な括り・切り取りを指すとき、「枠」ではなく **図式**（英：schema）を使う
- 根拠1：「枠」は日本語で視覚的なイメージが強すぎる（窓枠のような四角い実物を喚起する）
- 根拠2：本書が指したいのは、概念を包み込むような線的な括り・切り取りであり、四角い境界線ではない
- 根拠3：Bartlett 1932 / Rumelhart 1980 の **schema 理論**の翻訳系譜が認知科学で確立されており、「図式」がその標準訳である（`577CHBM3`, `V6DBC4WK`）
- 根拠4：頭脚一致は和声の外声／内声、タイポグリセミア、メロディのパラフレーズなど領域横断的に現れる構造であり、認知科学の標準語「図式（schema）」が領域横断性を引き受けやすい
- 適用例：「同じ図式を持つフレーズ」「音素配置の図式」など、概念的な括りを呼ぶ場面
- 「フレーム」も避ける：英語 frame の借用だが、依然「囲い」のニュアンスが残る
- 例外：複合語「枠組み」（framework）は別語として扱い、対象外
- 既存ドラフトでの未適用箇所：
  - `drafts/ch3_section_2_1_mikuru_three_layers.md` L132「同じフレームを持つフレーズ」「両端『あ…に』のフレームが共有」→ 統合時に「同じ図式を持つフレーズ」等へ置換
  - `drafts/ch1_section_4_3_alignment_addition.md` L20, L22 → 文脈確認のうえ置換
- 将来的にさらに適切な訳語が見つかれば一括置換の余地あり（暫定）
- 2026-05-23追加

### 規則16:音素・CVクラスを地の文で言及するときは鉤括弧で括る
- 「だ」「た」「だ／た」「し」「な」のような CV・音素クラスを地の文（説明的散文）で言及するときは、必ず鉤括弧「」で括る
- 理由：地の文の裸の仮名は「だが（接続詞 but）」「したら（条件形 if）」など、自然言語の語彙・形態素と紛れて読みづらい
- 例：**「だ」**はこの9モーラのなかで唯一の有声破裂音である
- 例外：歌詞引用内の太字強調（「なみ**だ**」のように引用文字列内の bold で十分明示できる場合）は対象外
- 2026-05-23追加（§2.4.2 で発覚した可読性問題への対応）

### 規則17:歌詞引用はひらがな統一
- 本書本文で歌詞を引用するときは、原典の混在表記（漢字／カタカナ／ひらがな）ではなく、**ひらがな統一**で引用する
- 理由：表記が混在した歌詞は読み流しを妨げ、音そのものの分析（CV・反復・呼応）に視覚的ノイズを持ち込む。ひらがな統一にすると音の連続だけが残り、分析対象に集中できる
- 適用範囲：本書本文の歌詞引用すべて
- 例：「カモンレッツダンス」→「かもんれっつだんす」、「みくる」（原典ひらがな）→「みくる」のまま
- CVクラス名も同様にひらがな統一（規則16と整合）：CV「だ」「た」「し」「な」など
- 例外：作業用ドラフト・歌詞ファイル（`lyrics/`）は原典準拠でよい。本書本文に取り込む段階でひらがな統一する
- 2026-05-23追加

### 規則18:4操作（並行・倒置・展開・圧縮）は出現順に依存する有向操作
- 並行・倒置・展開・圧縮はいずれも、楽曲内の**出現順**に基づいて判定する。同じ反復関係を**逆向き**に観察すれば別の操作になる
- とくに**展開**と**圧縮**は逆操作の関係にあるが、出現順が「短→長」なら展開（中間挿入）、「長→短」なら圧縮（中間抜去）として読む
- 同様に、**倒置**は「ABC が現れたあとに CBA が現れる」場合に成立する。「CBA が先に現れて ABC があとから現れる」場合は別の倒置の事例として独立に判定し、両者を「逆操作の関係」「対称」として両義的にまとめない
- **並行**も、累積（A → AA → AAA）と単独反復（A → A）はいずれも並行だが、累積を「圧縮の逆操作」として記述しない
- 根拠1：本書の「**想起と回帰**」、すなわち聞き手が時間軸を前向きに辿りながら音を聞き取っていくという立場（`core_positions.md`）と整合する
- 根拠2：本書の「**作詞は作ることではなく聞き取ること**」（同前）と整合する。書き手の設計図ではなく、聞き手の時間体験を基礎にする
- 根拠3：規則11（「距離」不使用）と同じく、本書全体で**時間軸の有向性**を守るための規則
- 違反例（避けるべき記述）：
  - 「展開と圧縮はペアをなす」── 同一の反復関係を両義的に扱ってしまう
  - 「AとBは展開・圧縮の対称配置である」── 出現順を曖昧にする
  - 「ABCとCBAは倒置の関係にある」── どちらが先に出るかを明示しない
- 適用例：§2.4.5 の sh-r 骨格 4単位は、出現順「しり → したら → しゃる → じぇねれ」で **展開→圧縮→展開** の3操作として読む
- 既存原稿で要点検の箇所：
  - 第1章 §1.4（4操作の定義）── 「逆操作の関係」「対称的」と書いている可能性あり
  - 第4章「リンダリンダ」展開・圧縮の対称分析（v1.3 で書かれた、CLAUDE.md記載の論点3「展開と圧縮の対称配置」）── 「対称」表現を出現順に書き換える要あり
  - 第3章 §2.1（「みらくる→ミクル」の圧縮、「ミクル→ミクルんるん」の累積）── 既に出現順で書かれているはずだが点検
- 2026-05-30追加（§2.4.5 執筆セッションでの誤読への反省として）

## 規則と理論の対応

これらの文体規則は、単なる好みではなく、理論の内容と対応している。

- 実体化する語を避ける ⟷ 楽曲を実体ではなく現象(ネットワーク)と捉える
- メタ記述を避ける ⟷ 作者を設計者ではなく聞き取る身体と捉える
- 断定の留保 ⟷ 有機的構造は例外を含むという立場

文体は理論の外部ではない。理論の生きた表現である。

## 文体の系譜

### 宮沢賢治「春と修羅」序との共鳴
- 「わたくしといふ現象」— 主体を現象として定義する語彙選択が一致
- 「有機交流電燈」— 機械的ではない、明滅する構造への志向が一致
- 「仮定された」— 断定の留保が一致

賢治序は文体規則の根源的な源泉の1つと推定される。
ただし本文中で明示しないという判断あり(references.md参照)。

## 沿革

### 出発点となった修正事例

**事例1**
- 修正前:「やってみせたことと、方法論的には同じである」
- 修正後:「行っている方法論とほとんど同じである」

**事例2**
- 修正前:「機械的に規則に従う**もの**は、生きた構造ではない」
- 修正後:「機械的に規則に従う**現象**は、生きた構造ではない」

**事例3**
- 修正前:「僕の立場は、シェーンベルクのこの姿勢を歌詞に適用しようというものだ」
- 修正後:「僕はシェーンベルクのこの姿勢を歌詞に適用したい」
