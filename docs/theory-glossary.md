# 理論用語集

## この理論の位置づけ

**この理論は「XとYで韻が踏める」的な測定のツールではない。**作詞をするときのものの考え方・物差しであり、楽曲を分析する際に使うツールである。たとえば曲先で、所与の5音にどう言葉を与えるかという場面で使う（2026-08-13、X で Sagishi 氏に相談する際にやおきが明示）。

この線引きは `docs/network-design-plan.md` のお試しツールの設計原則——「ツールは判定せず、描くだけ」「この理論の要点は『指させる/記述できる』であって自動判定ではない」——と同じ地点から出ている。**下に並ぶ定義は、判定の基準ではなく記述の道具として読む。**

## この文書の使い方

lyricstheory の分析で使う理論用語の定義。**この文書が定義の参照先**であり、スキルやカードに写しを置かない。

Chat（lyric-analysis-memo スキル）からは以下で読める。

```
https://raw.githubusercontent.com/yaoki/lyricstheory-astro/main/docs/theory-glossary.md
```

典拠は原則として COMITIA156 本（`comitia156/full_manuscript_v1.6_integrated_20260531.md`、`comitia156/comitia156-structure.md`、`comitia156/comitia156-handover.md`）。定義を変更するときは、本側との整合を確認すること。本以外を典拠とする項目には、その旨を各節に明記する。

## 用語の使用方針（2026-08-13 制定）

新しい理論用語を立てるとき、次の手続きを踏む。

**この節が要る理由**は 2026-08-13 に分かった。「母音連続」を16枚のカードで使っていたところ、Sagishi 氏から「学術用語の母音連続（vowel sequence / hiatus）は**母音が子音を挟まずに隣接する状態**を指すので衝突する」と指摘された。裏を取ると事実だった。**立項しないまま語を使い続けると、既成事実だけが積み上がる。**

### 1. 衝突チェックの相手

隣接領域の2つを基準にする。

| 領域 | 相手 |
|:---|:---|
| 音韻論・押韻論 | [Sagishi の note](https://note.com/yasumisha) |
| 音楽理論 | [SoundQuest](https://soundquest.jp/) |

**どちらも用語の方針を明文化して公開している**（SoundQuest の「[用語の使用方針](https://soundquest.jp/use-of-terms/)」は「他流派との視点の違いを明確にするため」と目的を述べている）。この文書と同じ作法を持つ相手を基準に据える、という判断である。

### 2. 採らないと決めた語

| 語 | 退けた理由 |
|:---|:---|
| **通奏低音** | 誤用が多い。デジタル大辞泉が比喩義（「常に底流としてある考えのたとえ」）まで立項するほど流通しているが、通奏低音は記譜・演奏の慣習であって保続する音ではない。音楽的素養のある読者に「用語を分かっていない」と伝わる |
| **母音調和** | 素性（前後・円唇・高さ等）の共有であって同一性ではない。トルコ語の a/ı/o/u は互いに異なる母音だが調和している。加えて日本語では上代特殊仮名遣の有坂・池上法則＝アルタイ語族説という**係争中の論点の名前**であり、持ち込むと意図しない学説的主張として読まれる |
| **クリシェ** | 半音階的な動きが構成的だが、子音には順序尺度がない（n→k は「一歩」ではなく、上行も下行もない）。加えてデジタル大辞泉の語釈が「ありきたりな決まり文句。常套句」で、分析語のつもりが否定的評価に読まれる |
| **母韻・類韻（assonance）** | **既に地位が定まっている用語である。**別の意味で使うことはできない（下記「既存概念との距離」を参照） |

**採る余地を残す語**: 「同母音連続」。術語としての占有は確認できなかったが、素直に読むと「同じ母音の隣接」（おかあさん型）になり hiatus の内側に留まる。使うなら誤読のリスクを併記すること。

### 3. 既存概念との距離

| 概念 | この体系との関係 |
|:---|:---|
| **hiatus（母音接続・連母音）** | 母音が**子音を挟まずに**隣接する状態。「あい」「這う」。子音を挟むことを前提とするこちらの記述とは**排他的**である |
| **assonance（母韻・類韻）** | 「母音が同じで子音が異なる」という核は一致する。ただし**隣接を要件としない**（複数行にまたがって分散していてもよい）ので、こちらの現象を含むより広い概念にあたる。また assonance は「韻を踏んでいる」という**判定**の語彙圏に属し、この文書冒頭の位置づけ（測定のツールではない）と噛み合わない |

### 4. 借用の作法

音楽理論など他分野から借りるときは、**出典を明記し、借用元との差分を書く**。前例は「回帰反復」（沼野雄司『ファンダメンタルな楽曲分析入門』）で、下記の節に「借用元の定義をそのまま踏襲していない。判定基準を差し替えて使っている」と明記してある。

**判断の軸は2つあり、どちらも同格である。**

1. 既に地位の定まった用語と衝突しないか
2. **読み手が直感的に理解できるか**——作図の原則（「図はブログを読みに行かなくても単体で伝わる強度を持たなければならない」）を用語にも当てる。読者は作詞者・音楽ファンであって、言語学や和声学の訓練を受けているとは限らない

この2つが逆を向くことがある。「母音調和」は**直感的には最もよく伝わるのに内容は誤り**で、その典型だった。

## 想起・短期反復・回帰反復

### 前提：想起

**反復の美的効果は、聴取者が先行する音を想起することによって生じる。** 想起が起きなければ、同じ音が二度鳴っていても反復としては体験されない。したがって「同じ音がある」ことと「反復がある」ことは同じではない。

### 想起が起こる二つの条件

原典（`comitia156-structure.md`）の記述をそのまま引く。

> - 想起が起こる条件①：**経過時間が短い**こと（短期反復）——直前に聞いた音の記憶が鮮明なうちに同じ音が来る
> - 想起が起こる条件②：**構造的な対応**があること（回帰反復）——経過時間が離れていても、楽曲内の対応する位置にある音が想起を誘発する

用語集の定義は以下。

| 用語 | 定義 |
|---|---|
| **短期反復** | 経過時間が短いことによる想起 |
| **回帰反復** | 構造的対応による想起 |

つまり **回帰反復は「離れているのに想起される」ケースの名前**であり、それを可能にしているのが楽曲構造上の位置の対応である。

### 具体例

`src/content/elements/tadashii-machi-return-repetition.mdx`（椎名林檎『正しい街』）。

```
1-b　あたしはそれをむしした
2-b　あたしはそれもむしした
```

一番と二番の同じ位置。あいだにはサビ・間奏・二番のAメロが挟まり、経過時間は長い。それでも想起されるのは、「一番のこの位置」と「二番のこの位置」が構造的に対応しているからである。

### よくある誤り

**1. 「回帰＝もとに戻る」という一般語として使う**

誤り。回帰反復は**想起がなぜ起きたかの分類名**であって、音が戻る動きの名前ではない。

**2. 「離れた反復＝回帰反復」と距離で判定する**

誤り。**「距離」は棄却された概念である**（2026-04-05 確立）。空間メタファーとしての「距離」は、意味の距離／時間の距離／音韻空間上の距離を混同させるため使わない。離れているだけでは想起は起きない。判定基準は構造的対応の有無である。

代替表現：時間的・量的概念（スパン／span）、具体的記述（同一フレーズ内／フレーズ間／曲全体）、または本用語（短期反復／回帰反復）。

**3. 四操作と同じ層に置く**

誤り。四操作（並行・倒置・展開・圧縮）は**順序と密度の操作**、短期／回帰は**想起がなぜ起きるかの条件**である。軸が異なるので、「この反復は倒置であり、かつ回帰反復である」は両立する。

### 判定手順

1. その反復は想起されるか。されないなら反復として記述しない
2. 想起の理由が経過時間の短さなら → **短期反復**
3. 経過時間は離れているが、楽曲構造上の対応（一番と二番の同位置、対句、AメロとA'メロ、サビの各回など）があるなら → **回帰反復**

### 英語表記について

**「回帰反復」の出典は沼野雄司『ファンダメンタルな楽曲分析入門』**（2017、第3章 pp.24-32）からの借用である（2026-07-27 訂正。それ以前の記録は石桁真礼生『楽式論』としていたが誤り）。同書 p.25 に「この離れた反復を、『回帰反復』と呼ぶことにしよう」とあり、**沼野自身の命名**である。対語は「繰り返し反復」（AA / AA'）。

**英語の確定訳は存在しない**（2026-07-27、現物確認）。同書は日本語文献で英語併記がない。したがって slug の `return` は西洋形式論の慣用に基づく採用にとどまり、**確定訳ではない**。英語で書く場合はこの留保を明示すること。

**借用元との定義の差分に注意。** 沼野の回帰反復は「離れた反復」＝**形式の記述**である（ABA / ABCA / ABABA）。一方この体系の回帰反復は「構造的対応による想起」＝**想起がなぜ起きたかの分類**であり、距離による判定を明示的に棄却している。**借用元の定義をそのまま踏襲していない。判定基準を差し替えて使っている。**

なお沼野自身も回帰反復の説明に「想起」「記憶の喚起」を用いている（同書 p.31「3部形式と記憶」）。

**「想起」も暫定の語である。**本の告知文（`tasks/blog-comitia156-announcement.md:325`）に「想起は、現在の本書では暫定の語として導入されており、今後も呼称そのものを検討する余地があります」と明記されている。`english_edition/terminology.md` は `recall` を挙げているが状態は「踏襲」であり、**確定訳として扱わないこと**。

なお `recursion`（同 terminology.md の回帰の訳）は計算機科学の「再帰」と衝突するため採用しない。

## 反復の類型（CV反復／V反復／C反復）

定義は `../CLAUDE.md` の「反復の類型（`tags.repetition`）」節にある。frontmatter の値との対応もそちらに書いてある。

要点のみ再掲する。**この三つは類型であって単位ではない。** 単位は譜割シラブルとその内部の C・V である。

**この三つはパターンと方向を表す語である**（2026-08-02、やおき）。何が何と一致し、どちらからどちらへ向かうかを言う。したがって、パターンを見ていない観察にこの語を当ててはならない。下の「子音ピボット」がその例である。

## 子音ピボット（2026-08-02 立項）

軸となる子音が保たれたまま、母音を変えながら、行の全長にわたって散らばって現れる現象。初出は 2014 年の記事「[椎名林檎の子音ピボット](../src/content/blog/2014/sheena-ringo-repeated-consonance.mdx)」。

**子音ピボットは分布の観察であって、パターンではない**（2026-08-02、やおき裁定）。

想定はこうである。**子音の分布の密度が高められることで、暗示的に楽曲の安定性やフィーリングが作られる。** 初出記事も、子音を固定し母音を変化させることで音声的な印象を安定させ、同時に変化させていける、と書いており、あわせて**リスナーには分かりにくいテクニックである**ことを述べている。11 年を通じて一貫した見立てである。

### ここから出るガードレール

1. **形式ラベル（ABA・ABC・AABBAB 等）を付けない。** 型のラベルは「聴き手が型として聴き取れるもの」を書く記法である。ピボットの想定は逆で、聴き取られないまま安定性が作られることにある。型を掲げると、想定そのものと矛盾する。2026-08-02 に3枚（`there-will-be-love-there-t-pivot` / `-k-pivot` / `seishun-t-pivot-aba`）からラベルを外した
2. **`tags.repetition` を持たせない。** C反復 / V反復 / CV反復はパターンと方向の語である（上記）。2026-08-02 に `type: pivot` の13枚すべてから外した
3. **図に分析のフレームのバッジを出さない。** バッジは `tags.repetition` を表示するものだから、2 と同じ理由で当たらない。図の左上に掲げるのは軸そのもの（「カ行子音」）と、それが持続する範囲を示す矢印である
4. **図は呼応の弧を描かない。** 弧は「どれとどれが対応するか」を主張する記号で、それはパターンの記述にあたる。ピボットの図（`kind: pivot`）は、行の全長のうちどこに軸の音が散っているか、その粗密だけを見せる

母音がどう動くかに触れること自体は禁じられない（子音が保たれ母音が変わる、がピボットの定義の一部だから）。禁じられているのは、**母音の並びを型として記述すること**である。「1行目の母音は e・u・a、2行目は u・a・a・e・a」は分布の記述として成立するが、「ABC ／ BCCAC をなす」はパターンの主張になる。

## 母音の保続（2026-08-13 立項）

同一の母音が、子音を挟みながら、連続する拍にわたって保たれる状態。

```
な・か・な    母音 a・a・a（替わらない）／ 子音 n・k・n（替わる）
```

**間隔ゼロの V反復である。**「連続とは、反復の特殊例である」「いずれも間隔がゼロの反復として読める」（`kuchibue-consecutive-as-special-case`）。したがって `tags.repetition: v` を持ち、子音ピボットのガードレール2（`repetition` を持たせない）はここには当たらない。**両者を分けているのは層ではなく、間隔ゼロか散在かである。**

### 借用元と、その差分

**音楽理論の保続音（Orgelpunkt / pedal point / 持続低音）から借りている。**保続音は「他声部の和音進行にかかわらず、ある声部において長く延ばされる音」で、その上部に旋律・和声が変化・展開させられる。借りるのは「**一方が保たれ、他方が動く**」という構造である。

- **和声に相当する第三項がない。**保続音は和声との摩擦によって定義され、協和 → 不協和 → 協和の三相を持つ。音韻にはそれがない。**ここでは「変化する周囲との対比で同一が保たれる」という構造だけを取る**
- **位置の指定を持たない。**保続音は通常バス（最低声部）に置かれるが、母音にその指定はない
- **持続と打ち直しの差は問題にならない。**保続音の項は「音の減衰が速い楽器では**同一音の繰り返し**やトリルなどで代用される」と明記している。日本語の歌唱は母音を伸ばさず次のモーラへ進むので、減衰の速い楽器と同じ条件にあたる。**この点は差分ですらない**

### 二声ではなく、一声の二パラメータである

保続音・クリシェ・斜行・共通音——音楽理論が「保たれる／動く」を語るとき、それは**同時に鳴る複数の声部**を前提にしている。ある音と別の音が同時に鳴るとき、それは二つの出来事である。

ところが /na/ の n と a は二つの出来事ではない。**一つの音節を二つのパラメータに分解したもの**である。母音と子音は同時に鳴る二声ではなく、同じ一本の流れの二つの属性である。

**この差は借用を無効にしない**（差分を明記して使う、という上記の作法どおりである）。ただし、音楽理論の側にこの構造を扱う語がほとんど無いこと自体は記録に値する。**日本語のモーラは、音楽がポリフォニーで行うことを一本の線の内部で行っている。**

### 保たれる層と、動く層

母音の層では配置の軸が立たない。同じ母音が並ぶだけなので、倒置しても形が変わらない。**かわりに子音の層に配置が立つ。**

```
な・か・な              子音 n・k・n            中心を挟んで折り返す
こころとこころを        子音 k・k・r・t・k・k・r  一音を挟んで同じ並びが返る
```

**この二層は、別々のカードに割る。**題に両層を積まない。前例は `hello-again-consecutive-vowel-a3`（母音の側）と `hello-again-aba-na`（「な」の対称形）で、同じ「なかな」を扱う2枚が related で結ばれている。後者の本文が「同じ3モーラが、層によって別の形を見せている」と書いている。

### 退けた語

「母音連続」を 2026-07-27 から16枚で使っていたが、2026-08-13 に改めた。学術用語の母音連続（vowel sequence / hiatus）は**母音が子音を挟まずに隣接する状態**（「あい」「這う」）を指し、こちらの記述とは排他的である。Sagishi 氏の指摘による。**席を奪ったのではなく返した**、という経緯である。

## シラブル化（2026-08-15 立項）

文字表記ではなく、歌唱＝実演レベルの概念。ただし、これから述べるように歌詞の書き方にも規則性があるため、規範となる歌唱（オリジナルアーティストによる歌唱等）が参照され、文字表記レベルへの相互影響が見られる。

日本語の歌唱で、歌詞をモーラ単位ではなく英語型のシラブル単位に譜割りする指向。2モーラを1つの重音節（CVV・CVC）に見立て、メロディ1音——ひとつの音価——に乗せる。「けい」/kei/・「ない」/nai/ は二重母音による CVV、「きん」/kiN/ は撥音による CVC。

厳密にシラブル化が「起きている」わけではない。**指向を指す語である**。ボーカルの解釈や、いわゆる「返し」＝スピーカーやイヤフォンといったモニターによる環境変化によっても、実演は変化しうる。

### 複数バージョンの観察——意図とジャッジ

アルバムバージョン、LIVE、コンサートや弾き語りなど複数のバージョンを観察することで、むしろ書かれた歌詞と実演の差から、シラブル化が**意図されて起きているのか**を読み取れる。意図されている場合、**それが達成されているか／いないか**をバージョンごとに判定できる。

この「意図」とジャッジは、ノエル・キャロル『批評について』（森功次訳。原著 *On Criticism*, Routledge, 2009）が批評の中核に置く構造——作品の試み（意図）の帰属と、その達成度の評価——からの借用である。ただし全体は踏襲しない。差分が3つある。

1. キャロルにおいて評価は批評の目的だが、この理論では判断は入口であり、目的は評価軸を増やすことにある
2. 帰属の根拠は実演群——バージョン間で保たれるか揺れるか——に限定する。作者の証言から帰属しない。意図が作品から読めない以上、作品は引き受けていない
3. 不達成を作品の価値へ直結させない。差自体が観察になる

### 条件は音節構造の側だけでは決まらない

Mr.Children『雨のち晴れ』の「むーど」の「むー」は、構造だけを見れば長音による CVV だが、3つの音高（Des-C-As）が当てられて下行するため取らない（出典カード: `ame-nochi-hare-syllabification`）。1音価に乗ることが条件に含まれる。すなわち判定材料は言語の側（音節構造）とメロディの側（音価）の両方にあり、言語側だけでは決まらない。

### 借用元と、その差分

syllabification は一般音韻論の標準用語で、音素列に音節構造を割り当てる一般プロセスを指す。あらゆる言語のあらゆる発話で常に働き、起きない発話がない。

この体系の「シラブル化」はそれと排他ではないが、差分が2つある。

1. 一般プロセスではなく、日本語歌唱での**マークされた選択**を指す。起きていない箇所（1音符1モーラ）との対比でのみ意味を持つ
2. 判定材料に**メロディ条件**（1音価に乗ること）を含む。標準の判定材料は言語の音韻規則のみ

構造の記述語「重音節」（CVV・CVC = 2モーラ）は Sagishi から借りている。過程・指向の名（シラブル化）と構造の名（重音節）は補完関係にあり、構造を記述するときは従来どおり Sagishi の語を使う。

### 退けた語

| 語 | 退けた理由 |
|:---|:---|
| **音節化** | 標準 syllabification の直訳で、全言語で常に起こる一般プロセスの名。特定の指向の名にすると一般義と衝突する。加えて 2015 年の Dragon Night 記事で、やおき自身が「音節」を「何を指すのか曖昧なまま使われやすい用語」として読者に非推奨と明言済み。自サイト内の一貫性が崩れる |
| **閉音節化** | CVC 側しか覆わない。実例3つのうち2つ（けい・ない）は二重母音 CVV——開いたまま重い音節——であり、外延が足りない。CVV を「閉音節化」と呼ぶと誤用になる |
| **CVC化** | 同じ狭さ。posfie 記事題（2022）では「シラブル化（CVC化）」と併記したが、CVV と CVC を区別する現行の記述では精度が下がる |
| **重音節化** | Sagishi の確立した構造名「重音節」を過程名へ転用することになる。重音節の成立は構造だけで決まるが、シラブル化はメロディ条件を持つため、内包が一致しない |
| **シラビック化** | 声楽用語のシラビック様式（歌詞の1音節に1音符、対語はメリスマ）と紛れる。シラビック様式は言語の音節を所与とする語で、単位の乗り換えを含まない |

### 典拠

本（COMITIA156）には現れない。blog 2014「宇多田ヒカル」論（初出。「閉音節化」による対比の中で）→ blog 2015「Dragon Night」（モーラ／シラブルの読者向け定義）→ posfie 2016「ペルセウス」→ posfie 2022「ひこうき雲・ロビンソン」（point 231）の系譜。

本が定義する単位語「**譜割シラブル**」とは別の語である。譜割シラブルは単位（楽譜上で1拍・1メロディ音符に対応する音のまとまり）、シラブル化はその単位が英語型に寄る指向。

### 半シラブル化との対

2014 年の宇多田論は、モーラ性を弱めてシラブル的に聴かせる型（シラブル化）に対し、**モーラ性を保ったままシラブル的に聴かせる**型を「半シラブル化」と名づけて対比した。2026-08-16 に立項済み（下記）。**畳むのがシラブル化、閉じるのが半シラブル化**という対をなし、メロディ条件の入り方が逆になる。

## 半シラブル化（2026-08-16 立項）

日本語の歌唱で、モーラの等拍性を保ったまま、モーラの境界に切れ目を立てて各モーラを閉じさせる指向。1モーラが CVC として聴こえる。

「あたらしい」を「あ・たらしい」と切ると、「あ」は次の子音を先取りして /at/ になる。モーラの数も音価の配分も変わらないまま、日本語には無いはずの閉じた音節が擬似的に生じる。

シラブル化と同じく、厳密に「起きている」わけではない。**指向を指す語である。**

### シラブル化との対

畳むのがシラブル化、閉じるのが半シラブル化、という対をなす。

| | 単位に起きること | メロディ |
|:---|:---|:---|
| シラブル化 | 2モーラが1つの重音節へ畳まれる | 1音価に乗る |
| 半シラブル化 | 1モーラがその位置のまま閉じる | 1音価1モーラが保たれる |

**メロディ条件の入り方が逆になる。** シラブル化は判定材料に「1音価に乗ること」を含むが、半シラブル化は「畳まれていないこと」を前提とする。等拍性が壊れて2モーラが1音へ畳まれたなら、それはシラブル化であって半シラブル化ではない。すなわち同じ譜割の上で両者は両立しない。

判定は、まずメロディが単位を畳んでいるかで分かれる。畳んでいればシラブル化、畳まずに切れ目だけが立っていれば半シラブル化。

### 手段

2014 年の初出が挙げた3つ。

1. 単純な母音の発音を強調し、その前後のモーラを分節する
2. 特定の子音の直前で自然に発生する切れ目を強調し、その前後のモーラを分節する
3. な行・ま行の直前に撥音「ん」を挿入し、その前後のモーラを分節する

2 が gemination（子音重複化）にあたる。1 と 3 はあたらない。

### 借用元と、その差分

gemination は一般音韻論の標準用語で、子音が長く発音される現象を指す。日本語の促音、イタリア語の doppie がこれにあたる。posfie 2022 の「ジェミネイション」の用法は標準義と一致している。ただし**半シラブル化と同義ではない**。上の3つのうち 2 だけを覆う手段の名であって、指向の名ではない。

**juncture（連接）** は、語や形態素の境界が音声としてどう現れるかを扱う標準用語である。2014 年の定義文が「日本語の音に**内在する**切れ目を強調する」と書くとき、その切れ目は juncture にあたる。差分はシラブル化のときと同じ構造で2つある。

1. 境界の一般的な現れではなく、切れ目を**強調する選択**を指す。強調されていない箇所との対比でのみ意味を持つ
2. 強調が**閉音節を生む**ところまでを含む。juncture 自体は音節構造の変化を含意しない

**この衝突は日英で非対称である。** 日本語の「切れ目」は日常語なので、日本語で書くかぎり標準用語圏に触れない。英語へ訳した時点で juncture と重なる。

英語名にも注意が要る。semi-syllabification は標準用語として存在しないが、近接語が2つある。

| 語 | 何を指すか | 距離 |
|:---|:---|:---|
| semi-syllable | minor syllable（弱音節） | **逆を向く。** 半シラブル化はモーラを軽くするのではなく、閉じて重くする |
| semi-syllabary | 半音節文字。文字体系の型 | 対象が正書法であって発話ではない |

### 退けた語

| 語 | 退けた理由 |
|:---|:---|
| **閉音節化** | 2014 年の初出では、この語をシラブル化（日本語ロック型）の側で使っている。同じ語を半シラブル化へ移すと系譜が混線する。シラブル化の立項でも別の理由（CVC 側しか覆わない）で退けている |
| **CVC化** | シラブル化の立項で既に退けた語。半シラブル化は CVC しか作らないので外延は足りるが、対の片側だけで採ると対が非対称になる |
| **宇多田カット** | 2015 年の記事が「前回は『宇多田カット』と呼んでいます」と書いている（2014 年の本文には現れず、図中にあると見られる）。特定のアーティスト名を含むため、他の曲へ適用しにくい |

### 典拠

blog 2014「宇多田ヒカル」論（初出。定義と3つの手段）→ blog 2015「Dragon Night」（再説明。「宇多田カット」の呼称）→ posfie 2022「ひこうき雲・ロビンソン」（point 231。ジェミネイションによる実例）。

シラブル化と系譜を共有する。分かれるのは 2014 年の初出時点で、そこで既に対として立てられている。

## 四操作

Schoenberg の**動機操作論**に着想を得て、本書が独自に定義した操作の体系。対象は動機・フレーズ・反復であり、十二音技法の音列操作（原型・反行・逆行・逆反行）とは**対象も定義も別**である。

英訳は `comitia156/style_rules.md` 規則14（2026-05-20 確定）に従う。**この四語は確定訳であり、庭の側で別語を立てない。**

| 操作 | 定義 | 軸 |
|---|---|---|
| **並行**（parallel） | 同じ順序での反復。ABC → ABC | 順序 |
| **倒置**（retrograde） | 逆順での反復。ABC → CBA | 順序 |
| **展開**（expansion） | もとの並びが順序保存的に保たれたまま、間隙に新しい要素が挿入される。AC → AXC は最短記法 | 密度 |
| **圧縮**（contraction） | もとの並びの一部要素が脱落し縮減される。ABC → AC。「あさか」→「あか」のように要素が消える | 密度 |

**英語表記の注意**：倒置に `inversion` を当てない。十二音技法の Inversion は**音程反転（反行）**であり別概念である。規則14 が明示的に不採用としている。

**注意**：ここでシェーンベルクの語（retrograde 等）を借りるのは、英語圏音楽理論との対応関係を読者に開くためであって、操作を同一視するためではない（規則14 の根拠より）。「逆行に対応する」といった同定表現を書かないこと。

### ノーテーション：A・B・C と X・Y・Z

**A・B・C** は対応を持つ要素に当てる。同じ記号は同じ音、または類音を指す。

**X・Y・Z** は**フィギュアの外から来た、対応を持たない要素**に当てる（2026-08-09 確定）。

ライムスキーム記法で、韻を踏まない行を x で示す慣習に準じる。Pat Pattison『Songwriting: Essential Guide to Lyric Form and Structure』p.36「RHYME SCHEME」は、black/attack/wall/fall を "a b a b"、black/wall/release/fall を "x a x a" と記し、"x" is always used to show unrhymed lines と述べている。Pattison はこの種の表記法を **notation** と呼ぶ（2026-08-09、やおきが原典を確認）。

本書は形式ラベルを大文字で書くので、X も大文字で揃える。

展開で挿入される要素は X 系列で書く。「だした」→「だしかった」は ABA → ABXYA（`tadashii-machi-expansion-dashita`）。

**挿入物に C・D を当てない理由**は、対応を持つ要素と同列に見えるためである。展開の定義は「対応が保たれたまま、対応を持たない要素が間隙に入る」ことなので、その区別が記号に出ていないと定義そのものが読み取れない。

**射程は展開に限らない。** X は「対応を持たない」を表す記号であって、「展開で加わった」を表す記号ではない。対応を持たない音を挟む倒置などにも同じ記号を使う。

### 前提：フィギュア（figure）

**四操作は、2つ以上の要素が並んで形をなしている場合にのみ適用できる。** 単独の音は順序を持たないため、並行・倒置という軸そのものが立たない。この「形をなした並び」を**フィギュア**と呼ぶ（2026-08-01 確立）。

**音韻的ゼクエンツもフィギュアを前提とする。**

語は**楽式分析の「音型」からの借用**である。ただし借用元がどこまで同じものを指すかは未検討であり、定義の差分は取っていない。

具体例は `src/content/elements/houkiboshi-cv-repetition-kana.mdx`（Mr.Children『箒星』）。「かな」の反復には並行が言えるが、同じ箇所から取れる /k/ 単独の反復には言えない。

### 未決：並べ替え

順序の軸は現在2値（同順＝並行／逆順＝倒置）しかないが、三要素の並びは 6 通りある。ABC→ACB や BAC は名前を持たない。

回転（ABC→BCA / CAB）は、切れ目を一つ入れれば二構成素の倒置として書けるため倒置に吸収される。したがって名前がないのは**一組だけを入れ替える型**である。

**隣接する二要素の入れ替えも倒置に吸収される**（2026-08-09 追加）。ABA → AAB は一組だけの入れ替えだが、動かない先頭 A を切れ目とすれば、後続の BA → AB という二要素の倒置として書ける（`tadashii-machi-retrograde-dashita`）。二要素の並びでは逆順と入れ替えが一致するため、切り出せたものは常に倒置になる。

順序の軸を「並べ替え」に一般化し、並行と倒置をその特殊形として下に置く案が候補（2026-07-26 時点で未決）。

**注意**：倒置がどこまで届くかは、どの粒度で切るかに依存する。操作を記録するときは、どの粒度で見た操作なのかを併記しないと後から集計できない。

## 対応の三要素

出典は本ではなく、押韻研究者 Sagishi 氏（@sagishi0）との 2026-07-26 のやりとり（X 上の公開リプライ）。rhyme が効果を持つ条件を三つに分けたもの。

> ①音響の対応（同じ母音や子音か）
> ②時間の対応（同じ拍節の位置か）
> ③韻律の対応（同じメロディ・リズムパターンか）

> たとえ同じ4/4拍目で揃っていてもリズムパターンが全然違うペアだと、rhyme の効果は減衰するといえるので、周期性が感じられるペアかが重要ですね。

### 本体系との対応

**①はすでに持っている。** 反復の類型（CV／V／C反復）と同音／類音の区別が①にあたる。`tags.repetition` として機械可読になっている層。

**②③は、回帰反復の「構造的対応」の内訳にあたる。** 回帰反復の定義は「構造的対応による想起」だが、その構造的対応が何を指すかは一語で括られたままだった。②は拍節上の位置の対応、③はメロディ・リズムパターンの対応として、その中身を割る。

**②は棄却された「距離」ではない。** ②が言っているのは位置の一致であって、隔たりの量ではない。空間メタファーには当たらない。

### ③は保留（2026-07-26）

**棄却ではなく保留である。** 理由は二つ。

1. 判定に必要な力（強勢による scansion、東京イントネーション）を yaoki が現在習得中である
2. **J-POP では③は変数ではなく与件であることが多い。** 1-A と 1-A' のメロディ・リズムパターンが一致するのは Aメロが二度繰り返される曲だからであり、書き手が選んだ結果ではない。常に揃っているものを指摘しても分析にならない

ラップでは事情が逆で、フローを書き手が動かせるため③は本物の変数になる。**同じ枠組みでも、対象が変われば変数と定数が入れ替わる。**

**②は残す。** どの語をどの拍節位置に置くかは作詞側が決めており、歌詞の変数だから。②を残して③を外す線引きは、「歌詞の側で動かせる層かどうか」で引かれている。

### ここから出るガードレール

- **譜割・メロディ・リズムパターンについて断定しない。** ③を保留している以上、根拠を持たない。カード本文に「リズムパターンが一致している」「同じメロディに乗る」等を書かない
- **③がない以上、位置を根拠に脚韻と断定しない。** ①で言えることだけを書く。「行をまたいで反復する」とは書けるが、「脚韻である」とは書けない
- **「拍」を単独で使わない。** 日本語音韻論では「拍」＝モーラ（本体系は服部四郎の慣例に従う）、音楽では「拍」＝ビートであり、同じ字が別物を指す。本体系は両方をまたぐため必ず区別する。モーラなら「モーラ」、音楽の拍なら「拍節」「ビート」と書く

## 同音・類音

| 用語 | 定義 |
|---|---|
| **同音** | 子音と母音が完全一致するペア（例：か／か） |
| **類音** | 一致しない部分がある近似ペア（例：た／だ／ら／な） |
| **有声↔無声交替** | 調音位置が同じで声帯振動のみ異なるペア（た↔だ、か↔が等）。類音の一種 |

一致が同音か類音かは、反復の類型（CV／V／C）とは**別の軸**である。両者を混ぜない。

## 状態（操作ではないもの）

操作の結果として、あるいは配置そのものから生じる、聴取上の状態。

### 隠蔽

操作ではなく**状態**。倒置・展開・圧縮を施すことで、反復が頭韻・脚韻のように明示的ではなくなる。J-POP の反復はこの隠蔽された状態にあることが多い。

### ぷよぷよ（仮称・2026-07-26）

隣接して同じ子音が並ぶとき、それぞれが一体のブロックとして融合し、**知覚される単位の数が減る**現象。`src/content/elements/tadashii-machi-mmss-fusion.mdx` を参照。

```
もむしした  □□△△×  →  □△×
```

**圧縮と混同しないこと。** 圧縮は要素が消える操作（ABC→AC）だが、ぷよぷよでは音は脱落しない。五音はそのまま残り、減るのは境界の数である。

隠蔽と対をなす。隠蔽が「反復が見えにくくなる方向」なら、ぷよぷよは「反復が塊として立ち上がる方向」である。ただし隠蔽が操作の結果として生じるのに対し、ぷよぷよに先立つ操作は要らない。

正式名は未確定。仮称である旨をカード本文に明記している（固有名から採る前例として「宇多田カット」がある）。

#### 適用範囲は未確定（2026-08-10 追加）

**「こころ」の「こ・こ」はぷよぷよではない**（2026-08-10、やおき裁定）。**理由は未特定である。**「まだ判断できないが違う」という状態のまま、可否だけが確定している。

上の定義（隣接して同じ子音が並ぶ）だけでは、この否定例を排除できない。現時点で判明している可否は以下。

| 例 | 隣接する子音 | 可否 | 出所 |
|---|---|---|---|
| こころ（こ・こ） | 同音 | **不可** | 2026-08-10 やおき裁定 |
| つつみ（つ・つ） | 同音 | 可 | `hello-again-aab-tsu` |
| もむしした（も・む／し・し） | 異母音／同音 | 可 | `tadashii-machi-mmss-fusion` |
| いまもむねに（ま・も・む／ね・に） | 異母音 | 可 | `hello-again-mmmnn-fusion` |

**同音か異母音かでは切れない。**「しし」が同音で可なので、「こころ」を同音であることによって排除できない。この軸は潰れている。

**定義を満たすように見えても、実例の可否はやおきの判断による。** 条件を推測して当てはめないこと。理由が言語化されたらこの節を差し替える。

### 対称形・鏡像（2026-08-02 立項）

操作ではなく**配置**。共通する音を軸として倒置形が接合された状態を指す。中心軸をもつ点対称の構造として記述できる。

「もし」とその倒置形「しも」が共通する「し」を軸に合成されたものとして「もしも」を読む、という記述がその定義にあたる。

**倒置と対称形は「同一」ではなく「包含」の関係にある**（2026-08-02 やおき裁定）。対称形は倒置の特殊例であり、倒置（順序の操作）が上位、対称形（軸を持つ配置）はその結果としての状態である。

- **軸を持たない倒置の複合は鏡像と呼ばない。** 塊レベルで倒置が働いていても、共通軸がなければ「単なる倒置の複合」として扱う
- **層が違うので規則18 と衝突しない。** 規則18 は四操作を出現順に依存する有向操作として書けと定める。対称形は無向の配置名なので、「ABA という配置」と書くことは禁止の対象ではない。禁じられているのは、倒置**関係**を「対称」と無向にまとめて操作の向きを消すことである
- 呼び分けの由来は厳密化にある。もともと直感的に「鏡像」「対称」と呼んでいた把握を、**共通音を軸にした倒置**として定義し直し、軸を持たない倒置と区別した経緯がある

**英訳は未確定。** 規則14 が確定させたのは四操作の訳語のみで、対称形・鏡像はその対象外である。

**注意**：図のテンプレート名はかつて `symmetry` だったが、この項の「対称形」と紛らわしいため 2026-08-02 に `single` へ改名した。図の側が指していたのは「1箇所に載る図」であって、対称性とは関係がない（`pair` と対になる名前である）。

**出典の位置づけ（重要）**：上記の定義は `comitia156/archives/dropped_from_final/02_chapter2_ponponpon.md` に書かれており、**頒布版の本文には載っていない**。頒布版に対称形・鏡像の定義はない。elements のカード群（`shido-to-hakuchuumu-1-mora-symmetric` / `kuchibue-aba-*` ほか）がタイトルで用いる語は、この削除章の定義に依拠している。なお削除章は鏡像を隠蔽と結びつけて論じているが、その接続は本項では引き継いでいない。

## 頭韻（2026-08-11 立項）

**頭韻は語頭で起こる**（2026-08-11、やおき確定）。助詞の頭も語頭に数える。数えないのは語中の音である。

| 位置 | 頭韻に数えるか | 例（スピッツ「涙がキラリ☆」） |
|---|---|---|
| 文節頭 | 数える | 「まま」の1つ目、「まなざし」 |
| 助詞の頭 | 数える | 「あけるまで」の「まで」 |
| 語中 | 数えない | 「まま」の2モーラ目 |

やおきの原文は「基本は文節の頭」である。これはおおよその目安として残るが、実際の判定の境目は**語頭か語中か**で引かれている（助詞「まで」は文節頭ではないが頭韻に数える、という裁定によって確定した）。

**行頭ではない。** 行頭で一致して見える例（`namida-ga-kirari-alliteration-o` / `-yo`）も、語頭で一致した結果として行頭にも現れているという順序で読む。

### 脚韻のガードレールとの切り分け

「対応の三要素」の③（韻律の対応）は保留中で、そこから「**位置を根拠に脚韻と断定しない**」というガードレールが出ている。**頭韻はこのガードレールに当たらない。** 語頭と語中の境目は歌詞のテキスト自体にある切れ目であり、譜割・メロディ・リズムパターンの判定を要しないためである。

### 数えなかった音の置き場

語中にあって頭韻に数えない音は、記述から消すのではなく**共起する単純反復**として置く（2026-08-11、やおき）。`namida-ga-kirari-alliteration-ma` の「まま」2モーラ目がこれにあたり、図でも色を付けずに枠だけ残してある。

なお「共起」「単純反復」はこの日にやおきが用いた語であり、定義の確定はしていない。
