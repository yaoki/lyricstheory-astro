## 想起・短期反復・回帰反復

### 前提：想起

**反復の美的効果は、聴取者が先行する音を想起することによって生じる。** 想起が起きなければ、同じ音が二度鳴っていても反復としては体験されない。したがって「同じ音がある」ことと「反復がある」ことは同じではない。

### 想起が起こる二つの条件

原典（`comitia156-structure.md`）の記述をそのまま引く。

> - 想起が起こる条件①：**経過時間が短い**こと（短期反復）——直前に聞いた音の記憶が鮮明なうちに同じ音が来る
> - 想起が起こる条件②：**構造的な対応**があること（回帰反復）——経過時間が離れていても、楽曲内の対応する位置にある音が想起を誘発する

用語集の定義は以下。

| 用語 | 定義 |
|---|---|
| **短期反復** | 経過時間が短いことによる想起 |
| **回帰反復** | 構造的対応による想起 |

つまり **回帰反復は「離れているのに想起される」ケースの名前**であり、それを可能にしているのが楽曲構造上の位置の対応である。

### 具体例

`src/content/elements/tadashii-machi-return-repetition.mdx`（椎名林檎『正しい街』）。

```
1-b　あたしはそれをむしした
2-b　あたしはそれもむしした
```

一番と二番の同じ位置。あいだにはサビ・間奏・二番のAメロが挟まり、経過時間は長い。それでも想起されるのは、「一番のこの位置」と「二番のこの位置」が構造的に対応しているからである。

### よくある誤り

**1. 「回帰＝もとに戻る」という一般語として使う**

誤り。回帰反復は**想起がなぜ起きたかの分類名**であって、音が戻る動きの名前ではない。

**2. 「離れた反復＝回帰反復」と距離で判定する**

誤り。**「距離」は棄却された概念である**（2026-04-05 確立）。空間メタファーとしての「距離」は、意味の距離／時間の距離／音韻空間上の距離を混同させるため使わない。離れているだけでは想起は起きない。判定基準は構造的対応の有無である。

代替表現：時間的・量的概念（スパン／span）、具体的記述（同一フレーズ内／フレーズ間／曲全体）、または本用語（短期反復／回帰反復）。

**3. 四操作と同じ層に置く**

誤り。四操作（並行・倒置・展開・圧縮）は**順序と密度の操作**、短期／回帰は**想起がなぜ起きるかの条件**である。軸が異なるので、「この反復は倒置であり、かつ回帰反復である」は両立する。

### 判定手順

1. その反復は想起されるか。されないなら反復として記述しない
2. 想起の理由が経過時間の短さなら → **短期反復**
3. 経過時間は離れているが、楽曲構造上の対応（一番と二番の同位置、対句、AメロとA'メロ、サビの各回など）があるなら → **回帰反復**

### 英語表記について

**「回帰反復」の出典は沼野雄司『ファンダメンタルな楽曲分析入門』**（2017、第3章 pp.24-32）からの借用である（2026-07-27 訂正。それ以前の記録は石桁真礼生『楽式論』としていたが誤り）。同書 p.25 に「この離れた反復を、『回帰反復』と呼ぶことにしよう」とあり、**沼野自身の命名**である。対語は「繰り返し反復」（AA / AA'）。

**英語の確定訳は存在しない**（2026-07-27、現物確認）。同書は日本語文献で英語併記がない。したがって slug の `return` は西洋形式論の慣用に基づく採用にとどまり、**確定訳ではない**。英語で書く場合はこの留保を明示すること。

**借用元との定義の差分に注意。** 沼野の回帰反復は「離れた反復」＝**形式の記述**である（ABA / ABCA / ABABA）。一方この体系の回帰反復は「構造的対応による想起」＝**想起がなぜ起きたかの分類**であり、距離による判定を明示的に棄却している。**借用元の定義をそのまま踏襲していない。判定基準を差し替えて使っている。**

なお沼野自身も回帰反復の説明に「想起」「記憶の喚起」を用いている（同書 p.31「3部形式と記憶」）。

**「想起」も暫定の語である。**本の告知文（`tasks/blog-comitia156-announcement.md:325`）に「想起は、現在の本書では暫定の語として導入されており、今後も呼称そのものを検討する余地があります」と明記されている。`english_edition/terminology.md` は `recall` を挙げているが状態は「踏襲」であり、**確定訳として扱わないこと**。

なお `recursion`（同 terminology.md の回帰の訳）は計算機科学の「再帰」と衝突するため採用しない。

## 四操作

Schoenberg の**動機操作論**に着想を得て、本書が独自に定義した操作の体系。対象は動機・フレーズ・反復であり、十二音技法の音列操作（原型・反行・逆行・逆反行）とは**対象も定義も別**である。

英訳は `comitia156/style_rules.md` 規則14（2026-05-20 確定）に従う。**この四語は確定訳であり、庭の側で別語を立てない。**

| 操作 | 定義 | 軸 |
|---|---|---|
| **並行**（parallel） | 同じ順序での反復。ABC → ABC | 順序 |
| **倒置**（retrograde） | 逆順での反復。ABC → CBA | 順序 |
| **展開**（expansion） | もとの並びが順序保存的に保たれたまま、間隙に新しい要素が挿入される。AC → ABC は最短記法 | 密度 |
| **圧縮**（contraction） | もとの並びの一部要素が脱落し縮減される。ABC → AC。「あさか」→「あか」のように要素が消える | 密度 |

**英語表記の注意**：倒置に `inversion` を当てない。十二音技法の Inversion は**音程反転（反行）**であり別概念である。規則14 が明示的に不採用としている。

**注意**：ここでシェーンベルクの語（retrograde 等）を借りるのは、英語圏音楽理論との対応関係を読者に開くためであって、操作を同一視するためではない（規則14 の根拠より）。「逆行に対応する」といった同定表現を書かないこと。

### 前提：フィギュア（figure）

**四操作は、2つ以上の要素が並んで形をなしている場合にのみ適用できる。** 単独の音は順序を持たないため、並行・倒置という軸そのものが立たない。この「形をなした並び」を**フィギュア**と呼ぶ（2026-08-01 確立）。

**音韻的ゼクエンツもフィギュアを前提とする。**

語は**楽式分析の「音型」からの借用**である。ただし借用元がどこまで同じものを指すかは未検討であり、定義の差分は取っていない。

具体例は `src/content/elements/houkiboshi-cv-repetition-kana.mdx`（Mr.Children『箒星』）。「かな」の反復には並行が言えるが、同じ箇所から取れる /k/ 単独の反復には言えない。

### 未決：並べ替え

順序の軸は現在2値（同順＝並行／逆順＝倒置）しかないが、三要素の並びは 6 通りある。ABC→ACB や BAC は名前を持たない。

回転（ABC→BCA / CAB）は、切れ目を一つ入れれば二構成素の倒置として書けるため倒置に吸収される。したがって名前がないのは**一組だけを入れ替える型**である。

順序の軸を「並べ替え」に一般化し、並行と倒置をその特殊形として下に置く案が候補（2026-07-26 時点で未決）。

**注意**：倒置がどこまで届くかは、どの粒度で切るかに依存する。操作を記録するときは、どの粒度で見た操作なのかを併記しないと後から集計できない。

## 対応の三要素

出典は本ではなく、押韻研究者 Sagishi 氏（@sagishi0）との 2026-07-26 のやりとり（X 上の公開リプライ）。rhyme が効果を持つ条件を三つに分けたもの。

> ①音響の対応（同じ母音や子音か）
> ②時間の対応（同じ拍節の位置か）
> ③韻律の対応（同じメロディ・リズムパターンか）

> たとえ同じ4/4拍目で揃っていてもリズムパターンが全然違うペアだと、rhyme の効果は減衰するといえるので、周期性が感じられるペアかが重要ですね。

### 本体系との対応

**①はすでに持っている。** 反復の類型（CV／V／C反復）と同音／類音の区別が①にあたる。`tags.repetition` として機械可読になっている層。

**②③は、回帰反復の「構造的対応」の内訳にあたる。** 回帰反復の定義は「構造的対応による想起」だが、その構造的対応が何を指すかは一語で括られたままだった。②は拍節上の位置の対応、③はメロディ・リズムパターンの対応として、その中身を割る。

**②は棄却された「距離」ではない。** ②が言っているのは位置の一致であって、隔たりの量ではない。空間メタファーには当たらない。

### ③は保留（2026-07-26）

**棄却ではなく保留である。** 理由は二つ。

1. 判定に必要な力（強勢による scansion、東京イントネーション）を yaoki が現在習得中である
2. **J-POP では③は変数ではなく与件であることが多い。** 1-A と 1-A' のメロディ・リズムパターンが一致するのは Aメロが二度繰り返される曲だからであり、書き手が選んだ結果ではない。常に揃っているものを指摘しても分析にならない

ラップでは事情が逆で、フローを書き手が動かせるため③は本物の変数になる。**同じ枠組みでも、対象が変われば変数と定数が入れ替わる。**

**②は残す。** どの語をどの拍節位置に置くかは作詞側が決めており、歌詞の変数だから。②を残して③を外す線引きは、「歌詞の側で動かせる層かどうか」で引かれている。

### ここから出るガードレール

- **譜割・メロディ・リズムパターンについて断定しない。** ③を保留している以上、根拠を持たない。カード本文に「リズムパターンが一致している」「同じメロディに乗る」等を書かない
- **③がない以上、位置を根拠に脚韻と断定しない。** ①で言えることだけを書く。「行をまたいで反復する」とは書けるが、「脚韻である」とは書けない
- **「拍」を単独で使わない。** 日本語音韻論では「拍」＝モーラ（本体系は服部四郎の慣例に従う）、音楽では「拍」＝ビートであり、同じ字が別物を指す。本体系は両方をまたぐため必ず区別する。モーラなら「モーラ」、音楽の拍なら「拍節」「ビート」と書く

## 同音・類音

| 用語 | 定義 |
|---|---|
| **同音** | 子音と母音が完全一致するペア（例：か／か） |
| **類音** | 一致しない部分がある近似ペア（例：た／だ／ら／な） |
| **有声↔無声交替** | 調音位置が同じで声帯振動のみ異なるペア（た↔だ、か↔が等）。類音の一種 |

一致が同音か類音かは、反復の類型（CV／V／C）とは**別の軸**である。両者を混ぜない。

## 状態（操作ではないもの）

操作の結果として、あるいは配置そのものから生じる、聴取上の状態。

### 隠蔽

操作ではなく**状態**。倒置・展開・圧縮を施すことで、反復が頭韻・脚韻のように明示的ではなくなる。J-POP の反復はこの隠蔽された状態にあることが多い。

### ぷよぷよ（仮称・2026-07-26）

隣接して同じ子音が並ぶとき、それぞれが一体のブロックとして融合し、**知覚される単位の数が減る**現象。`src/content/elements/tadashii-machi-mmss-fusion.mdx` を参照。

```
もむしした  □□△△×  →  □△×
```

**圧縮と混同しないこと。** 圧縮は要素が消える操作（ABC→AC）だが、ぷよぷよでは音は脱落しない。五音はそのまま残り、減るのは境界の数である。

隠蔽と対をなす。隠蔽が「反復が見えにくくなる方向」なら、ぷよぷよは「反復が塊として立ち上がる方向」である。ただし隠蔽が操作の結果として生じるのに対し、ぷよぷよに先立つ操作は要らない。

正式名は未確定。仮称である旨をカード本文に明記している（固有名から採る前例として「宇多田カット」がある）。

### 対称形・鏡像（2026-08-02 立項）

操作ではなく**配置**。共通する音を軸として倒置形が接合された状態を指す。中心軸をもつ点対称の構造として記述できる。

「もし」とその倒置形「しも」が共通する「し」を軸に合成されたものとして「もしも」を読む、という記述がその定義にあたる。

**倒置と対称形は「同一」ではなく「包含」の関係にある**（2026-08-02 やおき裁定）。対称形は倒置の特殊例であり、倒置（順序の操作）が上位、対称形（軸を持つ配置）はその結果としての状態である。

- **軸を持たない倒置の複合は鏡像と呼ばない。** 塊レベルで倒置が働いていても、共通軸がなければ「単なる倒置の複合」として扱う
- **層が違うので規則18 と衝突しない。** 規則18 は四操作を出現順に依存する有向操作として書けと定める。対称形は無向の配置名なので、「ABA という配置」と書くことは禁止の対象ではない。禁じられているのは、倒置**関係**を「対称」と無向にまとめて操作の向きを消すことである
- 呼び分けの由来は厳密化にある。もともと直感的に「鏡像」「対称」と呼んでいた把握を、**共通音を軸にした倒置**として定義し直し、軸を持たない倒置と区別した経緯がある

**英訳は未確定。** 規則14 が確定させたのは四操作の訳語のみで、対称形・鏡像はその対象外である。

**注意**：図のテンプレート名はかつて `symmetry` だったが、この項の「対称形」と紛らわしいため 2026-08-02 に `single` へ改名した。図の側が指していたのは「1箇所に載る図」であって、対称性とは関係がない（`pair` と対になる名前である）。
